# Coordination status

The authoritative task state is in [`work/INDEX.md`](../work/INDEX.md) and each work item's own `tasks.md`. Active cross-agent handoffs are indexed in [`handoffs.md`](handoffs.md); each linked work folder's `coordination.md` and task contract are authoritative for assignment, progress, blockers, and return handoff.

Do not copy task histories or implementation reports into this file. Historical coordination notes are preserved in [the archived coordination log](archive/coordination-history.md).

## Current operating rule

One work item → one selected task → one work-local contract → one return handoff. Update the global registry only when an active handoff is added, returned, or blocked.
