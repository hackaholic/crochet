# Security Findings

This directory stores verified security findings from static, container, or dynamic audit runs.

### Finding Template:
```markdown
# Finding SEC-<ID> — <Title>

- **Severity:** Critical / High / Medium / Low
- **Category:** Secrets / SAST / Dependency / Container / Logic
- **Component:** <file or path>
- **Discovered Date:** YYYY-MM-DD
- **Status:** Open / Remediated / Exception Granted

## Description
<Details without disclosing sensitive values>

## Impact
<Exploitation scenario>

## Remediation
<Fix steps taken or needed>
```
